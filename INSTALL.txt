VOX WARP — install (Windows, FL Studio)

1. Copy the "Vox Warp.vst3" folder into:
     C:\Program Files\Common Files\VST3\
2. Open FL Studio > Options > Manage plugins > Find more plugins (or "Find installed plugins").
3. Load Vox Warp on a mixer insert of your vocal (or any) track.

It follows FL's project tempo for SYNC mods and reports its latency to FL so the
vocal stays lined up with the beat.
